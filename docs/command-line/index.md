# BlobTools Command Line

The command-line interface provides tools for creating, extending, filtering, validating, and visualising BlobDir datasets.

## Overview

This section covers:

- **[Commands](commands)** - Reference for all blobtools commands
- **[Tutorials](tutorials)** - Step-by-step walkthroughs

## Core Tools

BlobTools provides commands for:

- **create** - Build new BlobDir datasets
- **add** - Extend existing datasets with new data
- **filter** - Query and subset sequences
- **view** - Export and visualize data
- **host** - Run a local interactive viewer
- **remove** - Remove fields from an existing BlobDir
- **validate** - Check BlobDir compliance

## Getting Help

For any command, use the `--help` flag for detailed documentation:

```bash
blobtools [command] --help
```
