# BlobToolKit Documentation

Welcome to the BlobToolKit documentation. BlobToolKit is a modular genome assembly quality evaluation toolkit that helps you assess and visualize the quality of genome assemblies.

## What is BlobToolKit?

BlobToolKit provides tools for:

- Creating and managing blob plot datasets
- Filtering and analyzing assembly data
- Interactive visualization of genome quality metrics
- Validation and specification compliance
