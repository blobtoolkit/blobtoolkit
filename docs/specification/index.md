# BlobDir Format Specification

Technical documentation for the BlobDir JSON-based data format and associated tools.

## Overview

This section covers:

- **[BlobDir Format](blobdir-format)** - JSON schema and data structure
- **[Validator](validator)** - Tools and usage for schema validation

## About BlobDir

BlobDir is a standardized, portable format for storing genome assembly quality assessment data. It enables:

- Reproducible analysis workflows
- Data interchange between tools
- Long-term archival and sharing
- Validation against formal specifications

## Format Version

Current version: **1.0**

## Getting Started

To create a valid BlobDir, see the [Pipeline](../pipeline) or [Command Line](../command-line) guides.

To validate an existing BlobDir, use the [Validator](validator) tool.
